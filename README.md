### Features

- **Multi-Model Orchestration**: Claude, Kimi, GLM, GPT, Gemini integration
- **Parallel Background Agents**: Fire 5+ specialists simultaneously
- **LSP Integration**: Full Language Server Protocol support
- **AST-Grep**: Pattern-aware code search across 25 languages
- **Hash-Anchored Edits**: Zero stale-line errors
- **Skill-Embedded MCPs**: On-demand MCP servers
- **Claude Code Compatible**: All hooks, commands, skills work unchanged
